# Daily News

Private News-App (PWA) – täglich gegengecheckte Nachrichten und 3 Facts.
Inhalte werden mit Claude (Anthropic) recherchiert; nur öffentliche Nachrichten, keine persönlichen Daten.

- `vorschau/` – Testversion vor der Freigabe
- `daten/` – Tagesausgaben (`JJJJ-MM-TT.json`) + `index.json`
- `werkzeuge/` – Prüfung der Tagesdatei und Index
